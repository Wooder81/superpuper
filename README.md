# GAZYAVA — VST3 для FL Studio (Windows 10/11)

Вокальный плагин: **STUTTER** (захват и повтор фрагмента) и **REVERSE** (реверс + Reverse Transition).
C++17 / JUCE 8 / CMake. Нулевая задержка, моно и стерео, любые частоты и размеры буфера.

## Как получить GAZYAVA.vst3

### Вариант A — без установки Visual Studio (GitHub Actions)
1. Создайте репозиторий на github.com и загрузите в него содержимое этого архива (папка `.github` должна попасть в репозиторий).
2. Вкладка **Actions** → **Build GAZYAVA (Windows VST3)** → **Run workflow** (или он запустится сам после push).
3. Через ~5–10 минут откройте завершённый запуск → **Artifacts** → скачайте `GAZYAVA-VST3-Windows` → внутри папка `GAZYAVA.vst3`.

### Вариант Б — локально
1. Установите [Visual Studio 2022 Community](https://visualstudio.microsoft.com/) (нагрузка «Разработка классических приложений на C++»),
   [CMake](https://cmake.org/download/) и Git.
2. В PowerShell, в папке проекта:
   ```
   cmake -B build -A x64
   cmake --build build --config Release
   ```
   (JUCE скачается автоматически, нужен интернет.)
3. Результат: `build\GAZYAVA_artefacts\Release\VST3\GAZYAVA.vst3`

## Установка в FL Studio
1. Скопируйте **папку целиком** `GAZYAVA.vst3` в `C:\Program Files\Common Files\VST3\` (нужны права администратора).
2. FL Studio: **Options → Manage plugins → Find installed plugins** (убедитесь, что папка VST3 в списке путей и стоит *Verify plugins*).
3. Откройте **Mixer**, выберите вставку (insert) с вокалом, кликните на пустой слот эффекта → **GAZYAVA** (в списке установленных
   плагинов, раздел Effects/VST3). Либо Plugin database → Installed → Effects → VST3 → GAZYAVA и перетащите на вставку.
4. Плагин ставьте **первым** в цепочке вокала (до реверба и дилея).

## Как пользоваться
**STUTTER**
1. Включите `STUTTER` (плагин постоянно пишет вокал в буфер).
2. В нужный момент нажмите `CAPTURE` — последние N мс/долей вокала зафиксируются и начнут повторяться.
3. Длина: при `SYNC` — доля такта (1/2 … 1/32, темп и размер берутся из FL Studio), без `SYNC` — вручную в мс (knob LENGTH).
4. `HOLD` — повтор не останавливается; без него эффект сам вернётся к обычному вокалу через `DURATION` (в тактах, 1/16 … 8).
5. `SPEED` — частота повторов (loop = length / speed), `PITCH` — высота повторов (±12 полутонов), `MIX`, `FADE` — затухание на стыках повторов.
6. Повторный `CAPTURE` во время работы плавно подменяет фрагмент на следующем повторе.

**REVERSE**
- Включение `REVERSE` забирает последние LENGTH вокала (опционально только часть окна — `START`/`END`) и играет их задом наперёд.
- Режим **Transition**: одно нарастающее «втягивание» (громкость растёт к концу), затем плавный переход в живой вокал.
  `TRANSITION` — длина кроссфейда обратно, `AUTO RETURN` — вернуться к оригиналу после одного прохода (если выключен — реверс повторяется).
- Режим **Reverse**: перевёрнутые фрагменты повторяются, пока кнопка включена.
- `MIX`, `VOLUME`, `FADE`, `SPEED` (0.5–2x, меняет и тон), `SYNC` + доля такта (1/16 … 2 такта) или длина в мс.
- Включайте `REVERSE` сразу **после** слова, которое нужно «втянуть»: плагин реверсирует то, что уже прозвучало.

Автоматизация: параметры доступны хосту (в FL — иконка шестерёнки/«Browse parameters» → правый клик → Create automation clip).
`CAPTURE` и `REVERSE ON` удобно автоматизировать короткими «ступеньками».

## Честные ограничения (и почему)
- **Реверс «следующего» слова невозможен в реальном времени** без заглядывания в будущее. Плагин реверсирует уже прозвучавший вокал.
  Для точного «reverse перед словом» нужен либо lookahead с задержкой (PDC) — могу добавить как режим, — либо реверс записанного клипа.
- **Pitch в STUTTER — «ленточный» (varispeed):** меняет и тон, и период повтора вместе. Независимый pitch-shift без смены темпа
  требует гранулярного/фазового шифтера — следующий этап.
- Максимальные длины: stutter-фрагмент 4 с, reverse-окно 8 с, история 10 с.
- Тест с реальными DAW (FL Studio), проверка GUI на разных DPI и сохранения проекта выполняются у вас после сборки.

## Структура
```
Source/PluginProcessor.*   — хост-интерфейс, параметры, темп, bypass, выход, защита от клиппинга
Source/PluginEditor.*      — интерфейс
Source/Parameters.*        — все параметры (APVTS, сохраняются в проекте FL)
Source/DSP/AudioBufferManager.h  — кольцевой буфер истории
Source/DSP/StutterProcessor.*    — Stutter
Source/DSP/ReverseProcessor.*    — Reverse / Transition
Source/DSP/DspUtils.h            — softClip, ramp, smoothstep
Source/GUI/*                     — LookAndFeel, кнопки, ручки, метры
tests/dsp_test.cpp               — офлайн-проверка DSP без JUCE
```
## Лицензия
JUCE распространяется под AGPLv3 или коммерческой лицензией. Для личного использования подходит AGPLv3;
для коммерческого распространения плагина нужна лицензия JUCE.
